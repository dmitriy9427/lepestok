# 03. Переходы между страницами и прелоадер

Файлы: `src/modules/pageTransition.ts`, `src/App.tsx`, `src/modules/preloader.ts`.

## Сценарий

1. Клик по ссылке → из центра распускается цветок и заливает экран (`cover`).
2. Под заливкой меняется страница.
3. В центре открывается «дыра» того же цветочного контура и растворяет заливку
   до краёв (`reveal`).

## Шейдер

Весь рисунок — один **фрагментный шейдер** на полноэкранном треугольнике.
Для каждого пикселя:

```glsl
float r = length(p);                                    // расстояние до центра
float a = atan(p.y, p.x);                               // угол
float petals = 0.5 + 0.5 * cos(6.0 * a);                // 6 лепестков
float R = uProgress * maxR * (0.78 + 0.32 * petals) + noise; // радиус фронта
float inside = smoothstep(-0.012, 0.012, R - r);        // внутри цветка?
```

Радиус фронта зависит от угла (`cos(6θ)` даёт шесть выступов) и шума (рваный
«живой» край), растёт с `uProgress` от 0 до 1. На кромке — узкий розовый
ободок: `exp(-|R − r| · 70)`. Для `reveal` маска просто инвертируется.

**Почему заливка, а не «растворение» самой страницы.** Чтобы растворить
страницу, её надо отрисовать в текстуру, а DOM в WebGL не снять без
html2canvas — медленно, ломает шрифты и видео. Заливка цветом бренда и
раскрытие новой страницы выглядят как растворение и идут на 60 fps.

Без WebGL — тот же сценарий на CSS (`clip-path: circle`). «Меньше движения» —
без перехода.

## Как остановить роутер на время заливки

React Router меняет страницу сразу. Чтобы старая страница была видна, пока
цветок её заливает, `usePageTransition` держит **показанную** локацию отдельно:

```tsx
const location = useLocation()           // куда хотим
const [shown, setShown] = useState(location)  // что показываем
// …ждём cover() и загрузку кода страницы, потом setShown(location)
<Routes location={shown}>
```

Если сменился только `?фильтр` или `#якорь` — страница та же, заливки нет.

## После смены страницы

`useRouteReset` под заливкой: ставит `<title>`, прокручивает наверх или к
`#якорю`, пересчитывает ScrollTrigger — и только потом `reveal()`.

Баг, найденный по ходу: ссылка «Доставка» из каталога (`/#delivery`)
недокручивала. Плавная прокрутка Lenis помнила высоту **старой** страницы и
упиралась в неё. Решение: дождаться, пока страница смонтируется
(`pageReady`), два кадра, `lenis.resize()` и только потом прокрутка.

## Прелоадер

Разметка и стили прелоадера — прямо в `index.html`: он виден с первого кадра,
ещё до загрузки JS. Модуль только двигает прогресс и убирает его.

- **Прогресс честный:** шрифты, постер первого экрана, запуск приложения.
  Видео (2+ МБ) не ждём — у него есть постер.
- **Не меньше 1,3 с** — чтобы цветок успел распуститься (иначе мелькнёт),
  **не больше 4 с** — ждать дольше хуже любой анимации.
- **Уход:** под прелоадер мгновенно кладётся заливка перехода тех же цветов
  (`coverNow()`), прелоадер гаснет, и заливка растворяется цветком —
  как при смене страниц. Один раз за сессию вкладки (`sessionStorage`).
