# Шпаргалка к собеседованию: «Лепесток»

**Как сделано «видео сквозь буквы»?**
Тёмный слой с белым текстом и `mix-blend-mode: multiply` поверх видео: белое ×
видео = видео, тёмное × видео ≈ тёмное. Прокрутка: секция 200svh со sticky-сценой,
GSAP ScrollTrigger со `scrub` двигает таймлайн. Закрепление — CSS, не JS: на
телефоне не дёргается при скрытии адресной строки.

**Как устроен переход между страницами?**
Фрагментный шейдер: радиус фронта = прогресс × (основа + cos(6θ)) + шум → цветок с
шестью лепестками. React Router меняет адрес сразу, а `<Routes location={shown}>`
показывает старую страницу, пока цветок её заливает; код новой страницы грузится
параллельно с анимацией.

**Почему свой стор, а не Redux/Zustand?**
Две сущности (корзина, избранное) — хватает `useSyncExternalStore`. Валидация
данных из localStorage, синхронизация вкладок через событие `storage`, стабильная
ссылка из `get()` — иначе бесконечный цикл рендеров.

**Почему цена не хранится в корзине?**
Хранится состав, цена считается из справочника. Иначе после смены цен в
localStorage «залипла» бы старая.

**Где хранить фильтры?**
В адресе: ссылкой можно поделиться, «Назад» работает как отмена, страница
переживает перезагрузку. Пустые значения не пишутся. Чужой адрес проверяется
по справочникам.

**Как тестировать логику со временем?**
Передавать «сейчас» аргументом (`slotsFor(date, now)`): функция чистая, тест
задаёт любое время. И проверять «сейчас» в момент отправки формы, а не загрузки.

**Как не мешать анимациями доступности?**
Все модули получают `ctx.reduced` и при «меньше движения» не запускаются или
показывают статичное состояние; скрытый текст — `opacity`, а не `visibility`;
Tab на невидимую кнопку проматывает интро.

**Какие баги были интересными?**
- Анимации появления в StrictMode: двойной запуск эффекта оставлял элементы
  прозрачными — учёт через `WeakSet`.
- IntersectionObserver не видит элемент, полностью скрытый `clip-path`.
- Якорь с другой страницы не докручивал: Lenis помнил высоту старой страницы.
- ScrollTrigger `start: 'top top'` снимал класс шапки на прокрутке ровно 0.
- Пути к картинкам на GitHub Pages: Vite не добавляет base в строки JS.

**Что бы улучшил?**
Настоящий бэкенд и оплату, оптимизацию картинок (AVIF, `srcset`), e2e-тесты
оформления заказа, разделение бандла (Swiper → слайдер кита).
