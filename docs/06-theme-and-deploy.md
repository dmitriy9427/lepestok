# 06. Тёмная тема и деплой

## Тема без вспышки

1. **Инлайн-скрипт в `<head>`** (`index.html`) до первой отрисовки читает выбор
   из localStorage и ставит `data-theme` на `<html>`. Нет выбора — CSS берёт
   системную тему через `prefers-color-scheme`. Страница сразу открывается в
   нужной теме, без белой вспышки.
2. **Цвета — CSS-переменные**, которые генерируются из SCSS-карт `$colors` и
   `$colors-dark` (`_abstracts.scss`). Тёмная тема — «ночной сад»: глубокий
   сливовый фон, приглушённые розовые.
3. **Переключатель-цветок** — модуль `theme-switch` кита. При смене темы он
   шлёт событие `theme:change`: его слушает canvas с цветами (`blossoms`),
   которому CSS-переменные не помогут — он рисует сам.
4. **Смена системной темы на лету** (`main.tsx`): если пользователь не выбирал
   тему вручную, при переключении темы в системе тоже шлём `theme:change`.

## Деплой на GitHub Pages

`.github/workflows/pages.yml` на каждый пуш: тесты → сборка с
`BASE_URL=/lepestok/` → публикация.

Сайт живёт в подпапке, и тут две ловушки:

- **Пути к файлам из `public/`.** Vite добавляет `/lepestok/` сам только в
  `index.html` и CSS. В строках JS/TSX — нет. Поэтому все пути идут через
  `asset('/photos/x.jpg')` (`src/lib/asset.ts`).
- **Прямая ссылка `/lepestok/catalog`.** На Pages нет сервера, который отдал
  бы `index.html` на любой путь, — будет 404. Решение: при сборке
  `cp dist/index.html dist/404.html`. Pages на неизвестный адрес отдаёт
  `404.html`, то есть само приложение, и роутер разбирает адрес.
