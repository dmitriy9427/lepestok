# 02. Первый экран: видео сквозь буквы

Файл: `src/modules/heroReveal.ts`, стили — `src/styles/sections/_home.scss`.

Сначала тёмный экран, в огромном слове «Лепесток» играет видео букета. При
прокрутке буквы растут, растворяются, и открывается всё видео с заголовком.

## Как «вырезаны» буквы

Никаких SVG-масок и canvas. Поверх видео лежит тёмный слой с **белым**
текстом и `mix-blend-mode: multiply`:

- тёмный × видео = почти тёмный;
- белый × видео = само видео.

То есть буквы становятся «окнами» в видео. Один `div`, работает во всех
браузерах, а текст остаётся текстом — его видят поисковики и скринридеры.

## Прокрутка без дёрганий

```
<section class="hero">            высота 200svh
  <div class="hero__stage">       position: sticky; height: 100svh
```

Секция вдвое выше экрана, а сцена внутри «прилипает» (`sticky`) — пока
прокручиваешь первую половину, сцена стоит на месте. **Закрепление делает
CSS**, а GSAP ScrollTrigger только двигает «ползунок» анимации
(`scrub: 0.6`) от 0 до 1 по мере прокрутки.

Почему не `pin` из ScrollTrigger: на телефоне при скрытии адресной строки
высота экрана меняется, и JS-закрепление дёргается. `sticky` + `svh` (высота
без адресной строки) — нет.

## Таймлайн

```ts
tl.fromTo(video, { scale: 1.45 }, { scale: 1 }, 0)   // видео приближено к центру букета
  .fromTo(word, { scale: 1 }, { scale: 9 }, 0)        // буквы растут
  .to(mask, { autoAlpha: 0 }, 0.3)                    // маска растворяется
  .fromTo(content, { opacity: 0, y: 60 }, { … }, 0.55) // выезжает заголовок
```

Числа в конце — позиции на общей шкале 0…1. В интро видео приближено, чтобы в
буквы попадали лепестки, а не светлый фон.

## Шапка над hero

Пока под шапкой тёмное интро, она прозрачная со светлым текстом
(`.is-over-hero`), на середине раскрытия — тёмный текст (`.is-hero-light`).
Тонкость, найденная в процессе: ScrollTrigger со `start: 'top top'` при
прокрутке ровно 0 считал, что мы «до начала», и снимал класс в самом верху.
Поэтому `start: -1`.

## Доступность и батарея

- **Tab** на невидимую кнопку → интро сразу проматывается к концу
  (`focusin`), иначе фокус ушёл бы на невидимый элемент.
- Текст скрыт только `opacity`, не `visibility` — скринридер его читает.
- **«Меньше движения»** — без интро: сразу постер и текст.
- Видео играет, только пока секция на экране (`onViewport`).
- iOS запускает видео сам только с `muted` + `playsInline`. React ставит
  `muted` свойством после вставки в DOM, поэтому модуль ставит его ещё раз.
