# 04. Анимации: появление, наведение, фон

## Появление при прокрутке (`src/modules/motion.ts`)

Один модуль на всё `<body>`. Элементы находятся **по классам** — атрибуты в
разметке не нужны:

```ts
const GROUPS = [
  ['.section-title, .product__title', 'title'],
  ['.bouquet-card-wrap, .review, .steps__item', 'card'],
  …
]
```

Каждый элемент получает `data-anim="card"`, а вид появления описан в CSS
(`_motion.scss`). Когда элемент входит в экран (IntersectionObserver), ему
ставится класс `is-in`, и CSS-transition делает остальное. Элементы,
появившиеся вместе, идут «волной» — задержка по порядку.

Три бага, которые здесь закрыты:

1. **Новые карточки.** Каталог фильтруется, корзина меняется — новые узлы
   появляются после запуска. MutationObserver подхватывает их, иначе они
   остались бы невидимыми.
2. **StrictMode.** В разработке React запускает эффекты дважды. Модуль
   отмечает уже наблюдаемые элементы в `WeakSet` — без этого после
   перезапуска часть элементов оставалась прозрачной навсегда.
3. **Рывок при наведении.** Transition появления перебивал собственный
   transition карточки (hover в отзывах дёргался). Поэтому после появления
   `data-anim` снимается — у элемента снова его родные transition.

Ещё одна тонкость: IntersectionObserver не видит элемент, полностью скрытый
через `clip-path`. Поэтому медиа появляются из размытия, а не «шторкой».

## Эффекты при наведении

Один делегированный `pointermove` на документ, только для мыши:

- **Блик** — CSS-переменные `--mx/--my`: светлое пятно следует за курсором
  (радиальный градиент в CSS).
- **Наклон** — `--tx/--ty` от −1 до 1: карточка букета поворачивается в 3D.

Модуль пишет только переменные, рисует CSS — дёшево и без React.

## Цветок из-за карточки (`BouquetCard.tsx`, `Bloom.tsx`)

При наведении из-за карточки «выползает» SVG-цветок цвета главного цветка
букета. Сторона — одна из шести точек на краю (`SPOTS`), выбирается по хешу
id букета: у каждой карточки своя, но всегда одна и та же. Точки подобраны
так, чтобы цветок перекрывал у соседей край фото, а не цену и кнопки.

## Фон: плывущие цветы (`src/modules/blossoms.ts`)

Canvas на весь экран под контентом. Цветы плывут вверх на **трёх глубинах**:
дальние мелкие и бледные, ближние крупнее; при прокрутке слои сдвигаются с
разной скоростью (параллакс). Курсор мягко расталкивает ближайшие цветы.

Производительность: каждый вид цветка рисуется **один раз** в отдельный
canvas (спрайт), а в кадре только `drawImage` с поворотом — дешевле, чем
каждый раз строить кривые лепестков. В тёмной теме спрайты складываются
режимом `lighter` — цветы светятся.
