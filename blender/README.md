# 3D-букет: модель из кода

`bouquet.py` строит букет «Утро в Провансе» (пионы в плёнке) целиком скриптом —
без ручного моделирования. Открыть результат и покрутить: `bouquet.blend`.

```bash
blender -b --python blender/bouquet.py              # модель + .blend + превью
blender -b --python blender/bouquet.py -- --no-render  # без рендера превью (быстрее)
```

| Файл                           | Что это                                                            |
| ------------------------------ | ------------------------------------------------------------------ |
| `bouquet.py`                   | скрипт: меняйте константы в разделе «Настройки»                    |
| `bouquet.blend`                | сцена (генерируется) — открыть в Blender                           |
| `preview.png`                  | рендер (генерируется) → постер `public/models/bouquet-poster.webp` |
| `../public/models/bouquet.glb` | модель для сайта (~700 КБ)                                         |

Постер после изменения модели:

```bash
node -e "require('sharp')('blender/preview.png').resize(600).webp({quality:82}).toFile('public/models/bouquet-poster.webp')"
```

## Как устроена модель

1. **Лепесток** (`add_petal`) — сетка вершин 9×9. Ширина по эллипсу (форма «ложки»),
   края подняты (`cup`), кончик загнут (`curl`), по краю волна (`ruffle`). Цвет вершин —
   градиент от тёмного у основания к светлому на кончике.
2. **Цветок** (`peony_mesh`) — 5 колец лепестков. Внутренние короткие и стоят почти
   вертикально (тугой «мячик»), внешние длиннее и раскрыты почти плашмя.
3. **Букет** — головки на «куполе» по спирали подсолнуха (равномерно, без сетки),
   повёрнуты наружу. Стебли — цилиндры к точке связки. Плёнка — 7 листов-кусков конуса
   с волнистым краем. Бант — лента, протянутая по кривой (`sweep`).
4. **Экспорт** — GLB. Три варианта пиона на 15 головок: одинаковые головки ссылаются на
   один меш (linked duplicates) — файл в разы меньше.

## Частые проблемы

| Симптом                            | Причина                                                                                  |
| ---------------------------------- | ---------------------------------------------------------------------------------------- |
| Рендер пустой                      | Камера и свет в Blender смотрят по **−Z**. `look_rotation(dir, '-Z')` — см. код.         |
| Цветы пропали, файл стал маленьким | Меши без граней: проверьте, что цикл добавления лепестков на месте (`len(me.polygons)`). |
| На сайте всё «выгоревшее», белое   | Слишком много окружающего света: `scene.environmentIntensity` в `scene.ts`.              |
| Белые «осколки» по краям лепестков | Блик sheen под скользящим углом — уменьшите `sheen` у материала Petals.                  |
| Толщина плёнки не попала в GLB     | glTF не знает модификаторов — их применяют перед экспортом (`apply_modifiers`).          |
